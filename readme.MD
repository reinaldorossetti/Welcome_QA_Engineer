# 🚀 Welcome QA Engineer: Guia para Iniciar na Qualidade de Software  

Seja muito bem-vindo(a) à área de Qualidade! Este é o seu kit de sobrevivência. Aqui você encontrará o caminho das pedras: o que aprender, referências de peso, cursos essenciais e os melhores canais para acompanhar.  

Muita gente acha que área de Qualidade é fácil, no entanto não é, isso é bem diferente de complexidade, desenvolvimento é muito mais complexo, no entanto a qualidade exige muito conhecimento do processo como todo e de Negócio, e principalmente Soft Skills.  

A área de QA (Quality Assurance) vai muito além de encontrar bugs; trata-se de garantir a excelência na experiência do usuário e a integridade do produto. Bora começar? 👇

## 📚 Bibliografia Essencial (Comece por aqui!)  

Antes de sair automatizando tudo, é crucial ter uma base teórica sólida. Estes livros são referências mundiais e oferecem o mindset correto:  

- **Agile Testing: A Practical Guide for Testers and Agile Teams** – Lisa Crispin & Janet Gregory (a bíblia do QA no mundo ágil)  
- **Clean Code** – Robert C. Martin (leitura obrigatória para escrever automação de qualidade e sustentável)  
- **The Art of Software Testing** – Glenford J. Myers (fundamentos clássicos que nunca saem de cena)  
- **Explore It!** – Elisabeth Hendrickson (dominando a arte dos testes exploratórios)

## 🎯 O Que um QA Júnior Precisa Saber (Roadmap de Mercado)  

Focado no que as vagas realmente pedem, aqui estão as competências-chave para se destacar:  

### 🧠 Fundamentos e Processos (segue em ordem de prioridade)  

- **1. Disciplina de Testes:** O foco principal é entender os tipos de testes (funcional/feature, regressivo, fumaça etc.), e quando aplicar cada um nas etapas do desenvolvimento do software. A Base para um QA é Testes e Processos/Documentação e Entendimento do Negócio.  
- **2. Planejamento:** Saiba elaborar o Plano de Testes de uma release e organizar as regressões. O Plano de Testes também envolve o Caderno/Cenários de Testes que serão executados e a elaboração da Massa de Dados.  
- **3. Documentação:** Produza roteiros/cadernos de testes com cenários manuais bem descritos.  
- **4. Gestão de Bugs:** Relate defeitos com clareza, incluindo passos para reproduzir o problema, evidências/logs e ciclo de vida.  
- **5. Agile & Ferramentas:** Conhecimento de SCRUM, o que é um quadro kanban, saiba o básico do Jira (ou similar) para gestão de tarefas. O Figma também é uma ferramenta muito importante para aprender, validar as telas com base no figma.  

### 💻 Técnico e Automação (segue em ordem de prioridade)  

- **1. Lógica de Programação:** Base para qualquer automação e para raciocínio estruturado.  
- **2. API Testing:** Teste e automatize APIs usando Postman, Robot Framework ou Rest-Assured. Testes de API são básicos no dia a dia do QA, então você precisa pelo menos ter conhecimento de como fazer e aprender o Postman.  
- **3. Banco de Dados SQL:** Tenha conhecimento introdutório de consultas, há diversos cursos de SQL na Udemy.  
- **4. Versionamento:** Domine comandos essenciais de Git/GitHub (`clone`, `pull`, `push`, `commit`).  
- **5. Web Testing:** Conheça frameworks como Selenium, Cypress, Playwright ou Robot. Mantenha ao menos um projeto no GitHub para demonstrar o básico. Dizer que não conhece nada, pode ser um ponto negativo na sua entrevista.

## 🤝 Soft Skills: O Diferencial do QA Júnior

Dominar ferramentas é importante, mas a senioridade nasce da forma de pensar, comunicar e resolver problemas. O QA moderno é um influenciador da qualidade. Lembra-se que as empresas contratam baseado no perfil técnico e demitem por falta de soft skills, isso vale para todos da área de Tecnologia.  

Competências comportamentais críticas:  

- **Comunicação Assertiva e Não Violenta:** Reporte falhas sem apontar culpados e traduza impactos com clareza para devs e Product Owners.  
- **Pensamento Crítico e Analítico:** Questione requisitos, avalie riscos e antecipe problemas.  
- **Empatia com o Usuário:** Seja o advogado do usuário final e levante usabilidade comprometida, mesmo sem erro técnico.  
- **Negociação e Persuasão:** Defenda a qualidade com argumentos baseados em risco quando for preciso adiar entregas.  
- **Adaptabilidade (Resiliência):** Requisitos mudam; mantenha o foco e o equilíbrio emocional em ambientes ágeis.

### 📚 Leitura Obrigatória para Soft Skills em TI:

- **Comunicação Não-Violenta** – Marshall B. Rosenberg  
- **Soft Skills: The Software Developer's Life Manual** – John Sonmez  
- **Como Fazer Amigos e Influenciar Pessoas** – Dale Carnegie  
- **Mindset: A Nova Psicologia do Sucesso** – Carol S. Dweck  
- **O Codificador Limpo (The Clean Coder)** – Robert C. Martin
